The dashboard is designed to help users understand both absolute values and relative positions, such as how a country ranks globally or how it compares to its regional peers. It also enables users to interactively select multiple countries for side-by-side comparison and explore statistical comparisons like peer averages and significance tests.

To achieve this, We used Streamlit to build a clean, interactive, and visually appealing dashboard that supports exploratory learning, data-driven insights, and comparative analysis — all in one place.

🎯 Goals
1. Let users compare CO₂ and GHG data between countries and regions.
2. Allow users to select multiple countries at once for comparison.
3. Make it easy to see global rankings and how each country stands.
4. Provide statistical comparisons like peer averages and significance tests.
5. Build a clean, interactive, and visually appealing dashboard.
